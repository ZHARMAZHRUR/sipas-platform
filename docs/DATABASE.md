# Database Design

## SIPAS

Sistem Informasi Pondok Asrama Santri

Version 1.0

---

## Tujuan

Database SIPAS dirancang agar:

- Mudah dikembangkan.

- Mendukung kebutuhan administrasi pondok.

- Siap untuk penambahan fitur di masa depan.

---

## Database Engine

- PostgreSQL (Supabase)

---

## Database Version 1.0

### Master Data

- Roles

- Users

- Students

- Dormitories

- Rooms

### Attendance

- Attendance Sessions

- Attendance Records

### Permission

- Leave Permissions

### Violations

- Violation Categories

- Violations

### Announcement

- Announcements

---

## Future Expansion

Fitur berikut akan ditambahkan pada versi selanjutnya sehingga database akan disesuaikan apabila diperlukan:

- QR Code Attendance

- Face Recognition Attendance

- Multi Face Recognition

- Parent Portal

- Mobile Application
